# ctrlgrp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native macOS background app that binds applications to number keys, RTS control-group style: `option+N` focuses or launches the app in slot N, `option+shift+N` binds the frontmost app to slot N at runtime.

**Architecture:** SwiftPM package with two targets. `CtrlgrpCore` is a pure-logic library (slots, config parsing, the two-layer binding model, frontmost tracking, the switch decision tree) with no AppKit dependency, fully unit-tested. The `ctrlgrp` executable is thin AppKit glue: Carbon global hotkeys, NSWorkspace activation, the HUD panel, config file watching. The build artifact is a `ctrlgrp.app` bundle so distribution is drag-into-Applications.

**Tech Stack:** Swift 6, SwiftPM (no Xcode required), AppKit, Carbon.HIToolbox (hotkeys), ServiceManagement (login item), os.Logger. Test-only dependency: apple/swift-testing.

## Global Constraints

- Language: Swift 6, `swift-tools-version: 6.0`, platform floor `.macOS(.v14)`.
- Zero third-party runtime dependencies. The only package dependency is
  `apple/swift-testing`, used by the test target only.
- Bundle id: `com.pgrekovich.ctrlgrp`. App name: `ctrlgrp`. Version `0.1.0`.
- Zero macOS permission prompts: no Accessibility, no Input Monitoring. Never
  add an API that triggers one.
- Config path: `~/.config/ctrlgrp/config.json`. The app reads it and **never
  writes it**.
- No animations anywhere. Performance first: fully event-driven, no polling.
- Slots are the digits 1-9 and 0, in that keyboard order.
- The daemon runs as an accessory app: no dock icon, no menu bar item.
- Comments explain constraints the code cannot show, not what the next line does.
- No em dash (`-` only) in any file, including docs and commit messages.

## Verified environment facts

These were probed on the target machine (macOS 26.5.2, Swift 6.3.3, Command
Line Tools only, no Xcode). Do not re-litigate them:

1. `RegisterEventHotKey` works from a plain binary with no permission prompt.
   All 21 hotkeys (10 focus + 10 bind + 1 HUD) register with status `noErr`.
2. `NSRunningApplication.activate()` from an accessory `.app` bundle really
   raises another app on macOS 26, and activating the previously frontmost app
   afterwards restores focus. The spec's cooperative-activation risk is closed.
3. Digit key codes are **not** sequential: `kVK_ANSI_5 == 23` and
   `kVK_ANSI_6 == 22`. Always use the named constants, never literals.
4. `XCTest` is absent from a CLT-only install, and the bundled
   `Testing.framework` in CLT ships without its runtime dylib
   (`lib_TestingInterop.dylib`), so it compiles but cannot run. The
   `apple/swift-testing` package is the working path and resolves to 0.99.0. It
   emits a deprecation warning telling you to drop it once the toolchain copy
   works; that is expected here. Test source uses the same `import Testing` /
   `@Test` / `#expect` API as the toolchain version, so if full Xcode is ever
   installed, dropping the dependency is a Package.swift-only change.
5. `swift build -c release` links AppKit, Carbon, ServiceManagement and
   os.Logger fine without Xcode.

Why the library/executable split: a test target cannot import an executable
target that uses top-level code, and the split is what keeps the real logic
free of AppKit so it can be tested at all. Everything that can be a pure
function is one; the AppKit files are deliberately thin.

Concurrency model: every mutable type is `@MainActor`. Carbon delivers hotkey
events on the main run loop and the config watcher hops to the main actor
before touching state, so nothing crosses isolation.

```swift
/// One of the ten control-group slots, named by the digit key that selects it.
public struct Slot: Hashable, Sendable, CustomStringConvertible {
    public let digit: Int

    public init?(digit: Int) {
        guard (0...9).contains(digit) else { return nil }
        self.digit = digit
    }

    /// Parses a config key such as "3". Rejects anything that is not exactly
    /// one digit, so "12" and " 1" are errors rather than silent matches.
    public init?(key: String) {
        guard key.count == 1, let digit = Int(key) else { return nil }
        self.init(digit: digit)
    }

    public var description: String { String(digit) }

    /// Slots in the order the keys sit on the keyboard: 1 through 9, then 0.
    public static let all: [Slot] = ((1...9).map { $0 } + [0]).compactMap(Slot.init(digit:))
}
```

`Sources/CtrlgrpCore/Config.swift`:

```swift
import Foundation

/// The persisted layer of configuration. Written by hand only: ctrlgrp reads
/// this file and never writes it, so hand edits can never be clobbered.
public struct Config: Equatable, Sendable {
    public var defaults: [Slot: String]
    public var hudEnabled: Bool

    public init(defaults: [Slot: String] = [:], hudEnabled: Bool = true) {
        self.defaults = defaults
        self.hudEnabled = hudEnabled
    }

    public static let empty = Config()
}

/// A parsed config plus everything questionable that was skipped along the way.
public struct ConfigParseResult: Equatable, Sendable {
    public var config: Config
    public var warnings: [String]

    public init(config: Config, warnings: [String] = []) {
        self.config = config
        self.warnings = warnings
    }
}

public enum ConfigError: Error, Equatable {
    case malformedJSON(String)
}

extension Config {
    private struct DTO: Decodable {
        struct HUD: Decodable { var enabled: Bool? }
        var defaults: [String: String]?
        var hud: HUD?
    }

    public static func parse(_ data: Data) throws -> ConfigParseResult {
        let dto: DTO
        do {
            dto = try JSONDecoder().decode(DTO.self, from: data)
        } catch {
            throw ConfigError.malformedJSON(error.localizedDescription)
        }

        var defaults: [Slot: String] = [:]
        var warnings: [String] = []
        for (key, bundleID) in dto.defaults ?? [:] {
            guard let slot = Slot(key: key) else {
                warnings.append("ignoring invalid slot key \"\(key)\"")
                continue
            }
            guard !bundleID.isEmpty else {
                warnings.append("ignoring empty bundle id for slot \(slot)")
                continue
            }
            defaults[slot] = bundleID
        }

        return ConfigParseResult(
            config: Config(defaults: defaults, hudEnabled: dto.hud?.enabled ?? true),
            // Dictionary iteration order is unspecified; sorting keeps the
            // warning list stable for tests and for log diffing.
            warnings: warnings.sorted()
        )
    }

    /// Reads and parses the file, degrading to an empty config with a warning.
    /// A missing or broken config must never stop the app from starting.
    public static func load(from url: URL) -> ConfigParseResult {
        guard let data = try? Data(contentsOf: url) else {
            return ConfigParseResult(
                config: .empty,
                warnings: ["no config at \(url.path()), starting with no default bindings"]
            )
        }
        do {
            return try parse(data)
        } catch {
            return ConfigParseResult(
                config: .empty,
                warnings: ["could not parse \(url.path()): \(error)"]
            )
        }
    }

    public static var defaultURL: URL {
        FileManager.default.homeDirectoryForCurrentUser
            .appending(path: ".config/ctrlgrp/config.json")
    }
}
```

```swift
/// The two-layer binding model.
///
/// `defaults` come from the config file and survive reboots. The session
/// overlay comes from option+shift+N and is deliberately never persisted: a
/// restart returns to the hand-written defaults, the way a new RTS match
/// starts with fresh control groups.
@MainActor
public final class Bindings {
    private var defaults: [Slot: String]
    private var session: [Slot: String] = [:]

    public init(defaults: [Slot: String] = [:]) {
        self.defaults = defaults
    }

    /// Applies a reloaded config. Session bindings outrank defaults and must
    /// survive a config reload, so they are left untouched here.
    public func updateDefaults(_ newDefaults: [Slot: String]) {
        defaults = newDefaults
    }

    public func bind(_ bundleID: String, to slot: Slot) {
        session[slot] = bundleID
    }

    public func effective(_ slot: Slot) -> String? {
        session[slot] ?? defaults[slot]
    }

    public var effectiveAll: [Slot: String] {
        defaults.merging(session) { _, sessionValue in sessionValue }
    }
}
```

```swift
/// Remembers which app was frontmost before the current one, which is what
/// pressing an already-focused slot toggles back to.
@MainActor
public final class FrontmostTracker {
    public private(set) var current: String?
    public private(set) var previous: String?

    public init(current: String? = nil) {
        self.current = current
    }

    /// Feed every frontmost change. Repeats of the current app are ignored so
    /// `previous` always names a genuinely different app, which keeps
    /// toggle-back from degenerating into a no-op.
    public func didActivate(_ bundleID: String) {
        guard bundleID != current else { return }
        previous = current
        current = bundleID
    }
}
```

```swift
/// What pressing a slot should do. Deciding and doing are split so the whole
/// behavioural contract stays a pure function.
public enum SwitchAction: Equatable, Sendable {
    case doNothing
    case activate(String)
    case launch(String)
    case appMissing(String)
}

/// Everything the decision needs to know about the world at keypress time.
public struct Situation: Equatable, Sendable {
    public var target: String?
    public var isTargetFrontmost: Bool
    public var isTargetRunning: Bool
    public var isTargetInstalled: Bool
    public var previous: String?

    public init(
        target: String?,
        isTargetFrontmost: Bool = false,
        isTargetRunning: Bool = false,
        isTargetInstalled: Bool = true,
        previous: String? = nil
    ) {
        self.target = target
        self.isTargetFrontmost = isTargetFrontmost
        self.isTargetRunning = isTargetRunning
        self.isTargetInstalled = isTargetInstalled
        self.previous = previous
    }
}

public func decideSwitch(_ situation: Situation) -> SwitchAction {
    guard let target = situation.target else { return .doNothing }

    if situation.isTargetFrontmost {
        guard let previous = situation.previous, previous != target else { return .doNothing }
        return .activate(previous)
    }

    if situation.isTargetRunning { return .activate(target) }
    guard situation.isTargetInstalled else { return .appMissing(target) }
    return .launch(target)
}
```

`Sources/ctrlgrp/HotkeyManager.swift`:

```swift
import Carbon.HIToolbox
import CtrlgrpCore

/// Registers the global hotkeys through Carbon, which is the only mechanism
/// that grabs keys system-wide without asking for Accessibility or Input
/// Monitoring permission. Registered combinations are consumed, so option+1
/// no longer types a special character while ctrlgrp runs.
@MainActor
final class HotkeyManager {
    enum Trigger: Equatable {
        case focus(Slot)
        case bind(Slot)
        case toggleHUD
    }

    private static let signature = OSType(0x4347_5250) // 'CGRP'
    private static let bindIDOffset: UInt32 = 100
    private static let hudID: UInt32 = 200

    private let onTrigger: (Trigger) -> Void
    private var hotkeyRefs: [EventHotKeyRef] = []
    private var eventHandler: EventHandlerRef?

    init(onTrigger: @escaping (Trigger) -> Void) {
        self.onTrigger = onTrigger
    }

    /// Registers every hotkey and returns the ones that failed, described the
    /// way a user would recognise them. A collision with another app's global
    /// hotkey must not take down the remaining slots.
    func register(includeHUD: Bool) -> [String] {
        installHandlerIfNeeded()

        var failures: [String] = []
        for slot in Slot.all {
            guard let keyCode = KeyCodes.digits[slot.digit] else { continue }
            if !register(keyCode: keyCode, modifiers: UInt32(optionKey), id: UInt32(slot.digit)) {
                failures.append("option+\(slot)")
            }
            if !register(
                keyCode: keyCode,
                modifiers: UInt32(optionKey | shiftKey),
                id: Self.bindIDOffset + UInt32(slot.digit)
            ) {
                failures.append("option+shift+\(slot)")
            }
        }

        if includeHUD,
           !register(keyCode: KeyCodes.grave, modifiers: UInt32(optionKey), id: Self.hudID) {
            failures.append("option+`")
        }

        return failures
    }

    func unregisterAll() {
        for ref in hotkeyRefs { UnregisterEventHotKey(ref) }
        hotkeyRefs.removeAll()
    }

    private func register(keyCode: Int, modifiers: UInt32, id: UInt32) -> Bool {
        var ref: EventHotKeyRef?
        let status = RegisterEventHotKey(
            UInt32(keyCode),
            modifiers,
            EventHotKeyID(signature: Self.signature, id: id),
            GetApplicationEventTarget(),
            0,
            &ref
        )
        guard status == noErr, let ref else { return false }
        hotkeyRefs.append(ref)
        return true
    }

    private func installHandlerIfNeeded() {
        guard eventHandler == nil else { return }

        var spec = EventTypeSpec(
            eventClass: OSType(kEventClassKeyboard),
            eventKind: UInt32(kEventHotKeyPressed)
        )
        let context = Unmanaged.passUnretained(self).toOpaque()

        InstallEventHandler(
            GetApplicationEventTarget(),
            { _, event, userData in
                guard let event, let userData else { return OSStatus(eventNotHandledErr) }

                var hotkeyID = EventHotKeyID()
                let status = GetEventParameter(
                    event,
                    EventParamName(kEventParamDirectObject),
                    EventParamType(typeEventHotKeyID),
                    nil,
                    MemoryLayout<EventHotKeyID>.size,
                    nil,
                    &hotkeyID
                )
                guard status == noErr else { return status }

                // Carbon delivers hot-key events on the main run loop.
                MainActor.assumeIsolated {
                    Unmanaged<HotkeyManager>.fromOpaque(userData)
                        .takeUnretainedValue()
                        .handle(id: hotkeyID.id)
                }
                return noErr
            },
            1,
            &spec,
            context,
            &eventHandler
        )
    }

    private func handle(id: UInt32) {
        if id == Self.hudID {
            onTrigger(.toggleHUD)
            return
        }
        if id >= Self.bindIDOffset {
            guard let slot = Slot(digit: Int(id - Self.bindIDOffset)) else { return }
            onTrigger(.bind(slot))
            return
        }
        guard let slot = Slot(digit: Int(id)) else { return }
        onTrigger(.focus(slot))
    }
}
```

```swift
import AppKit
import CtrlgrpCore

/// The AppKit side of switching: reads the state `decideSwitch` needs, then
/// carries out whatever it decided.
@MainActor
final class AppActivator {
    private let workspace = NSWorkspace.shared

    var frontmostBundleID: String? {
        workspace.frontmostApplication?.bundleIdentifier
    }

    func situation(target: String?, previous: String?) -> Situation {
        guard let target else {
            return Situation(target: nil, previous: previous)
        }
        return Situation(
            target: target,
            isTargetFrontmost: frontmostBundleID == target,
            isTargetRunning: runningApp(target) != nil,
            isTargetInstalled: workspace.urlForApplication(withBundleIdentifier: target) != nil,
            previous: previous
        )
    }

    func perform(_ action: SwitchAction) {
        switch action {
        case .doNothing:
            break
        case .activate(let bundleID):
            guard let app = runningApp(bundleID) else {
                // It quit between the decision and now; launching is the
                // closest thing to what the user asked for.
                launch(bundleID)
                return
            }
            if !app.activate() {
                Log.warn("could not activate \(bundleID)")
            }
        case .launch(let bundleID):
            launch(bundleID)
        case .appMissing(let bundleID):
            Log.warn("no application installed for \(bundleID)")
        }
    }

    private func runningApp(_ bundleID: String) -> NSRunningApplication? {
        workspace.runningApplications.first { $0.bundleIdentifier == bundleID }
    }

    private func launch(_ bundleID: String) {
        guard let url = workspace.urlForApplication(withBundleIdentifier: bundleID) else {
            Log.warn("no application installed for \(bundleID)")
            return
        }
        let configuration = NSWorkspace.OpenConfiguration()
        configuration.activates = true
        workspace.openApplication(at: url, configuration: configuration) { _, error in
            if let error {
                Log.warn("could not launch \(bundleID): \(error.localizedDescription)")
            }
        }
    }
}
```

```swift
import AppKit
import CtrlgrpCore

/// Owns the app's state and wires the pieces together.
@MainActor
final class AppCoordinator {
    private let bindings: Bindings
    private let tracker = FrontmostTracker()
    private let activator = AppActivator()
    private let hudEnabled: Bool
    private var hotkeys: HotkeyManager?

    init() {
        let loaded = Config.load(from: Config.defaultURL)
        for warning in loaded.warnings { Log.warn(warning) }
        bindings = Bindings(defaults: loaded.config.defaults)
        hudEnabled = loaded.config.hudEnabled
    }

    func start() {
        observeFrontmostChanges()
        if let current = activator.frontmostBundleID {
            tracker.didActivate(current)
        }

        let hotkeys = HotkeyManager { [weak self] trigger in
            self?.handle(trigger)
        }
        let failures = hotkeys.register(includeHUD: hudEnabled)
        if failures.isEmpty {
            Log.info("ready, \(bindings.effectiveAll.count) slots bound")
        } else {
            Log.warn("could not register: \(failures.joined(separator: ", "))")
        }
        self.hotkeys = hotkeys
    }

    private func handle(_ trigger: HotkeyManager.Trigger) {
        switch trigger {
        case .focus(let slot):
            let situation = activator.situation(
                target: bindings.effective(slot),
                previous: tracker.previous
            )
            activator.perform(decideSwitch(situation))
        case .bind:
            break // Task 8
        case .toggleHUD:
            break // Task 10
        }
    }

    private func observeFrontmostChanges() {
        // Workspace notifications come from the workspace's own centre, not
        // the default one.
        NSWorkspace.shared.notificationCenter.addObserver(
            forName: NSWorkspace.didActivateApplicationNotification,
            object: nil,
            queue: .main
        ) { [weak self] notification in
            guard
                let app = notification.userInfo?[NSWorkspace.applicationUserInfoKey]
                    as? NSRunningApplication,
                let bundleID = app.bundleIdentifier
            else { return }

            MainActor.assumeIsolated {
                self?.tracker.didActivate(bundleID)
            }
        }
    }
}
```

```swift
import Foundation

/// Watches the config file's *directory* rather than the file itself. Editors
/// save by writing a temporary file and renaming it over the original, which
/// invalidates a file descriptor opened on the old inode; a descriptor on the
/// directory survives that and also catches the file being created for the
/// first time.
@MainActor
final class ConfigWatcher {
    private let url: URL
    private let onChange: () -> Void
    private var source: DispatchSourceFileSystemObject?
    private var descriptor: CInt = -1
    private var pending: DispatchWorkItem?

    init(url: URL, onChange: @escaping () -> Void) {
        self.url = url
        self.onChange = onChange
    }

    func start() {
        let directory = url.deletingLastPathComponent()
        try? FileManager.default.createDirectory(at: directory, withIntermediateDirectories: true)

        descriptor = open(directory.path(), O_EVTONLY)
        guard descriptor >= 0 else {
            Log.warn("cannot watch \(directory.path()), config reload is off")
            return
        }

        let source = DispatchSource.makeFileSystemObjectSource(
            fileDescriptor: descriptor,
            eventMask: [.write, .rename, .delete],
            queue: .main
        )
        source.setEventHandler { [weak self] in
            MainActor.assumeIsolated { self?.scheduleReload() }
        }
        source.setCancelHandler { [descriptor] in
            close(descriptor)
        }
        source.resume()
        self.source = source
    }

    func stop() {
        pending?.cancel()
        source?.cancel()
        source = nil
        descriptor = -1
    }

    /// A single save can produce several directory events. Coalesce them so
    /// the config is parsed once per edit.
    private func scheduleReload() {
        pending?.cancel()
        let work = DispatchWorkItem { [weak self] in
            MainActor.assumeIsolated { self?.onChange() }
        }
        pending = work
        DispatchQueue.main.asyncAfter(deadline: .now() + 0.15, execute: work)
    }
}
```

`Sources/ctrlgrp/HUDPanel.swift`:

```swift
import AppKit
import CtrlgrpCore

/// A borderless, non-activating overlay listing the current slots. It must
/// never take focus: the point is to look at it while another app stays
/// frontmost.
@MainActor
final class HUDPanel {
    private var panel: NSPanel?

    var isVisible: Bool { panel?.isVisible ?? false }

    func toggle(bindings: [Slot: String]) {
        if isVisible {
            hide()
        } else {
            show(bindings: bindings)
        }
    }

    func hide() {
        panel?.orderOut(nil)
        panel = nil
    }

    private func show(bindings: [Slot: String]) {
        let content = makeContentView(bindings: bindings)
        let size = content.frame.size
        let panel = NSPanel(
            contentRect: NSRect(origin: .zero, size: size),
            styleMask: [.borderless, .nonactivatingPanel],
            backing: .buffered,
            defer: false
        )
        panel.contentView = content
        panel.isOpaque = false
        panel.backgroundColor = .clear
        panel.hasShadow = true
        panel.level = .floating
        panel.ignoresMouseEvents = true
        panel.hidesOnDeactivate = false
        panel.collectionBehavior = [.canJoinAllSpaces, .stationary, .fullScreenAuxiliary]
        panel.setFrame(centeredFrame(size: size), display: false)
        // orderFrontRegardless, not makeKeyAndOrderFront: showing the HUD must
        // not change which app is frontmost.
        panel.orderFrontRegardless()
        self.panel = panel
    }

    private func centeredFrame(size: NSSize) -> NSRect {
        let screen = NSScreen.screens.first { $0.frame.contains(NSEvent.mouseLocation) }
            ?? NSScreen.main
        guard let visible = screen?.visibleFrame else {
            return NSRect(origin: .zero, size: size)
        }
        return NSRect(
            x: visible.midX - size.width / 2,
            y: visible.midY - size.height / 2,
            width: size.width,
            height: size.height
        )
    }

    private func makeContentView(bindings: [Slot: String]) -> NSView {
        let background = NSVisualEffectView()
        background.material = .hudWindow
        background.blendingMode = .behindWindow
        background.state = .active
        background.wantsLayer = true
        background.layer?.cornerRadius = 16

        let row = NSStackView(views: Slot.all.map { cell(for: $0, bundleID: bindings[$0]) })
        row.orientation = .horizontal
        row.spacing = 12
        row.alignment = .centerY
        row.translatesAutoresizingMaskIntoConstraints = false

        background.addSubview(row)
        let padding: CGFloat = 18
        NSLayoutConstraint.activate([
            row.leadingAnchor.constraint(equalTo: background.leadingAnchor, constant: padding),
            row.trailingAnchor.constraint(equalTo: background.trailingAnchor, constant: -padding),
            row.topAnchor.constraint(equalTo: background.topAnchor, constant: padding),
            row.bottomAnchor.constraint(equalTo: background.bottomAnchor, constant: -padding),
        ])
        // Resolve the constraints now: fittingSize is only meaningful after a
        // layout pass, and a zero-sized panel would be invisible.
        background.layoutSubtreeIfNeeded()
        background.frame = NSRect(origin: .zero, size: background.fittingSize)
        return background
    }

    private func cell(for slot: Slot, bundleID: String?) -> NSView {
        let iconView = NSImageView()
        iconView.imageScaling = .scaleProportionallyUpOrDown
        iconView.translatesAutoresizingMaskIntoConstraints = false
        NSLayoutConstraint.activate([
            iconView.widthAnchor.constraint(equalToConstant: 48),
            iconView.heightAnchor.constraint(equalToConstant: 48),
        ])

        let label = NSTextField(labelWithString: slot.description)
        label.font = .monospacedDigitSystemFont(ofSize: 13, weight: .semibold)
        label.alignment = .center
        label.textColor = bundleID == nil ? .tertiaryLabelColor : .labelColor

        if let bundleID {
            if let url = NSWorkspace.shared.urlForApplication(withBundleIdentifier: bundleID) {
                iconView.image = NSWorkspace.shared.icon(forFile: url.path())
            } else {
                // Bound to something that is not installed any more.
                iconView.image = NSImage(
                    systemSymbolName: "questionmark.square.dashed",
                    accessibilityDescription: nil
                )
                iconView.contentTintColor = .tertiaryLabelColor
            }
        } else {
            iconView.image = NSImage(
                systemSymbolName: "square.dashed",
                accessibilityDescription: nil
            )
            iconView.contentTintColor = .quaternaryLabelColor
        }

        let cell = NSStackView(views: [iconView, label])
        cell.orientation = .vertical
        cell.spacing = 6
        cell.alignment = .centerX
        return cell
    }
}
```

```swift
import Foundation
import ServiceManagement

enum LoginItem {
    /// Registers the app to start at login. Skipped when running out of the
    /// build directory, so development runs never install a login item that
    /// points at a path that will be deleted.
    static func ensureRegistered() {
        guard Bundle.main.bundleURL.path().contains("/Applications/") else { return }

        let service = SMAppService.mainApp
        switch service.status {
        case .enabled:
            return
        case .requiresApproval:
            Log.warn("login item needs approval in System Settings > General > Login Items")
        case .notRegistered, .notFound:
            do {
                try service.register()
                Log.info("registered as a login item")
            } catch {
                Log.warn("could not register login item: \(error.localizedDescription)")
            }
        @unknown default:
            return
        }
    }
}
```

````markdown
# ctrlgrp

RTS-style control groups for macOS apps. Bind applications to number keys and
switch with one keystroke.

- `option+N` focuses the app in slot N. Not running, it launches. Already
  frontmost, focus goes back to the app you came from.
- `option+shift+N` binds the frontmost app to slot N for this session.
- `option` plus the backtick key toggles a HUD showing all ten slots.

Slots are the digits 1-9 and 0. Hotkeys are bound to physical keys, so they
behave the same on any keyboard layout. While ctrlgrp runs, those combinations
no longer type their special characters.

## Install

Requires macOS 14 or newer.

```bash
make install
open /Applications/ctrlgrp.app
```

It registers itself as a login item on first launch from `/Applications`. No
Accessibility or Input Monitoring permission is needed.

To remove it: quit the app, then `make uninstall`.

## Configure

Create `~/.config/ctrlgrp/config.json`:

```json
{
  "defaults": {
    "1": "com.google.Chrome",
    "3": "com.googlecode.iterm2"
  },
  "hud": { "enabled": true }
}
```

`defaults` are the bindings restored on every launch. Edits are picked up
immediately, no restart needed, except for `hud.enabled` which is read at
launch.

Bindings made with `option+shift+N` live in memory only and are gone after a
restart, leaving the defaults in place. ctrlgrp never writes this file.

Find an app's bundle id with:

```bash
osascript -e 'id of app "Google Chrome"'
```

## Develop

```bash
make test   # unit tests for the pure logic
make run    # build the bundle and run it in the foreground
```

Logs go to the unified log and to stderr:

```bash
log stream --predicate 'subsystem == "com.pgrekovich.ctrlgrp"' --level info
```
````
